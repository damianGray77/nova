# Settings reference

Generated by `nova keys --md docs/keys.md` from the settings registry, `core/src/keys.inc` (docs/config-plan.md C1). Don't edit it by hand: change the registry and generate it again.

Every setting is a `key = value` line in a config file, or `--set key=value` on the command line. A setting left out takes its default. A key nothing reads is an error (a typo, most likely).

- **Kinds:** *switch* (true or false), *whole* (a whole number), *number*, *choice* (one of the options listed), *text*. *log* marks a rate spanning decades (a logarithmic knob on the page).
- **Computed:** a default or a maximum worked out from other settings, as the setting's text says. The default shown is the one with every other setting at its own default.
- **Families:** a key with a `<placeholder>` stands for one setting per member listed.
- **Needs:** the switch the setting depends on; it does nothing while that is off.

385 settings, 83 of them from 14 families; 11 hidden (tests and demos).
